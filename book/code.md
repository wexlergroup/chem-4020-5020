# Run the Code

The plots in the lecture notes are drawn by Python code, which each section keeps in the Source dropdown of the figure. The notebooks on this page hold the same code in a form that you can change and run again. They run entirely in the browser, so nothing needs to be installed and no account is needed.

## How to Use a Notebook

1. Open a notebook from the table below, or from the "Run the code" link at the top of its section.
2. Choose Run and then Run All Cells. Python needs about half a minute to start.
3. Change a number in a cell, and press Shift+Enter to run that cell again.

Each notebook holds the code cells of one section, each under the heading and the figure caption that it has in the notes, so that the figure numbers match.

Your changes are saved in your browser only. They do not change the notes, and nobody else sees them. To get the original notebook back, open the [file list](https://wexlergroup.github.io/chem-4020-5020/lite/tree/index.html), right-click the notebook, and choose Delete. The original returns the next time you open the notebook.
